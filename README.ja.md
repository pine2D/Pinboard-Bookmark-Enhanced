# Bookmark Enhanced

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [繁體中文（香港）](README.zh-HK.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | **日本語** | [Polski](README.pl.md) | [Русский](README.ru.md)

[Pinboard](https://pinboard.in)、Karakeep、linkding に対応した Chrome 拡張機能。AI タグと要約、翻訳・ハイライト付きリーダー、pinboard.in 用テーマ 13 種を備えています。

> **注意:** 設定でブックマークサービスを選択します。Karakeep と linkding は Pinboard アカウントなしで使えます。Pinboard は独立した**有料**サービスで、自分のアカウントと API トークンが必要です。本拡張機能は第三者製で、Pinboard との提携・出資・公式の承認はありません。

## 機能

### 保存
- **ワンクリック保存**：タイトル・説明・選択テキストを自動入力し、URL のトラッキングパラメーターを除去します
- **ショートカットと一括保存**：ポップアップを開かずに保存したり、ウィンドウ内のタブをまとめてブックマークしたりできます
- **オフラインでも保存**：いったんローカルキューに入り、再接続後に自動で再試行します
- **下書きが消えない**：ポップアップを閉じても、開き直せば続きから書けます

### タグ
- **AI タグ・要約**：広告・メニュー・サイドバーを除いた記事本文だけを読み取ります。API キーは自前で、17 のプロバイダーまたは任意の OpenAI / Anthropic 互換エンドポイントを使えます
- **タグ補完**：自分のタグ、Pinboard のおすすめ、ワンタップのプリセットから入力できます
- **タグ整理**：似たタグを統合し、ほとんど使わないタグを片付けます

### リーダー
- **どんなページもすっきりしたリーダーに**：目次・検索・脚注プレビュー付きの Markdown 表示。数式・図・表もきちんと表示されます
- **GitHub Discussions（試験対応）**：読み込み済みの本文とコメント、返信の階層、採用された回答を保持し、取得した範囲も表示
- **読みながらブックマークを管理**：ポップアップに戻らず、ブックマークを保存・編集・削除できます
- **5 色のハイライトとメモ**：翻訳しても、あとでページが書き換わっても、元の位置に残ります
- **ページ全体の翻訳とページへの質問**：対訳表示に対応し、回答には出典への引用が付き、クリックで該当箇所へジャンプします
- **質問と回答を引用付きで残す**：完了した回答を自動保存し、Google ドライブで同期します。ライブラリで履歴を確認し、リーダーで質問を続けたり、単独または記事と一緒にエクスポートしたりできます。一時的な会話は保存しません。
- **読みながら単語を調べる**：辞書の語義と発音を確認できます。保存した単語はワンクリックで Anki や Eudic に送れ、中英・英中のオフライン辞書パックも選べます。AI辞書の説明言語は表示言語と別に設定でき、単語帳は言語で絞り込めます。 辞書のポップアップは端をドラッグしてサイズを変えたり、サイドパネルへ移したりできます。表示場所を切り替えても、検索結果・選択した語義・生成中の処理はそのまま引き継がれます。Wikisource の作品から、その語を含む実際の一文を著者・出典つきで表示します。AI は使いません。
- **多言語オフライン辞書**：Yomitan v3 の ZIP ファイルをインポートすると、このデバイスで語義と読みを調べられ、辞書パックは Drive 同期や JSON バックアップには含まれません。 漢英・英漢辞書を含むすべてのオフライン辞書は、データを削除せずに無効にできます。 構造を認識できる語義は例文や語源と分けて表示し、その他の内容は項目の全文として読めます。旧形式で取り込んだ辞書は再インポートすると構造を再解析でき、保存済みの単語や辞書の有効・無効の設定は変わりません。
- **AI辞書**：まず母語または指定した言語で意味・発音・例文を確認し、必要なときに用法のポイントと語源を追加できます。補足の一部だけが有効な場合は、その部分を残して不足を表示します。結果全体は接続済みの Google ドライブで同期され、更新前の版も保持されます。辞書の結果と AI の内容は 1 列に並び、生成中はその場で進み具合が見え、保存する語義は下部に残ります。基本項目の自動生成は別途有効にします。
- **選択した文章を文脈から理解**：「解説」で今の記事における単語や段落の意味を確認できます。辞書では一般的な意味と使い方を調べられます。
- **ライブラリ**：ハイライト、ノート、保存した単語と会話を一か所で確認できます。辞書検索や単語の一括管理にも対応しています。辞書の検索結果から語義を選んで単語を保存し、編集可能な基本形で関連する語形をまとめられます。メモと学習状態は単語ごとに保持されます。
- **単語の情報をまとめてエクスポート**：専用の多言語Ankiノートタイプを選ぶと、つづりが同じでも言語が違う単語を区別できます。完全なTSVにはメモ、基本形、各文脈とその出典を保存でき、従来の6フィールド形式も引き続き使えます
- **送信もダウンロードも**：[Obsidian](https://obsidian.md)・Notion・NotebookLM・GitHub Gist・任意の webhook へ送信でき、`.md`・`.html`・`.epub` で電子書籍リーダーにも渡せます
- **読みながら観る**：YouTube と Bilibili の動画の横に、再生に合わせて流れる字幕を表示。AI タグと要約も字幕を直接読めます

### カスタマイズ
- **pinboard.in 用テーマ 13 種**（Dracula、Nord、Catppuccin、Solarized など）に、自分のカスタム CSS を重ねられます
- **[Wayback Machine](https://web.archive.org) へ自動アーカイブ**：保存したページごとにスナップショットを残すので、元のリンクが切れても読めます
- **バックアップと同期**：設定は Chrome Sync、単語帳・ハイライト・メモ・AI 辞書項目・会話履歴は自分の Google ドライブ で同期。JSON バックアップには設定・単語帳・ハイライト・メモを含められます
- **9 言語対応** · カスタマイズ可能なショートカット · ローカルファースト保存 · トラッキング一切なし

## インストール

**[→ Chrome ウェブストアからインストール](https://chromewebstore.google.com/detail/pinboard-bookmark-enhance/pnjndmjhljjbdlbejeenkepdalokfooh)**（推奨）

または、リリース ZIP を解凍して読み込む:
1. 最新の [リリース ZIP](https://github.com/pine2D/Pinboard-Bookmark-Enhanced/releases/latest) をダウンロード
2. 解凍
3. `chrome://extensions/` → **デベロッパーモード** を有効化 → **パッケージ化されていない拡張機能を読み込む** → 解凍したフォルダを選択

ソースディレクトリには、固定された開発用 ID が設定されています。そのため、テスト時には Chrome ウェブストア版と同じプロフィールで併用できます。リリース ZIP は Chrome ウェブストア版と同じ ID を使用するため、両方を同じプロフィールにはインストールできません。各デバイスで設定の同期を有効にすると、Chrome Sync で設定を共有できます。以前のリリース ZIP から移行する場合は、先に旧バージョンの設定ページで **バックアップをエクスポート** をクリックし、新しいリリースを読み込んだら **バックアップをインポート** を使ってください。

インストール後は**設定 → アカウント**でサービスを選択します。Karakeep または linkding のサイト URL と API トークンを入力し、**接続**を押してサーバーへのアクセスを許可します。URL にはサブパスも含めてください。localhost 以外は HTTPS が必要です。Pinboard の場合はポップアップに [API トークン](https://pinboard.in/settings/password) を貼り付けてログインします。

ポップアップ、リーダー、ショートカット、一括保存は選択したサービスを使います。Karakeep の「後で読む」は専用の非公開リストで管理し、既読にするとリストから外れます。アーカイブ状態は変更しません。linkding は未読フラグを使います。Pinboard のおすすめ、タグ整理、未読件数、サイト検索、タブセットは Pinboard 専用です。

単語帳、ハイライト、メモ、AI 辞書の保存内容、Ask 履歴は、3 サービス共通の個人ライブラリに保存します。サービスの変更やログアウトでは切り替わりません。更新時は現在の Pinboard ライブラリを引き継ぎ、過去の別アカウントは統合しません。ブックマークのキャッシュ、下書き、オフラインキューは元の接続に紐づきます。linkding からログアウトして接続し直すと新しい接続として扱われ、以前の接続に残っていた保存待ち項目は自動では再試行されません。

## プライバシー

トラッキング、解析、テレメトリは一切ありません。新規ユーザーでは、設定と認証情報は既定でこのデバイスに保存されます。通常の設定同期はデバイスごとに個別に有効化します。認証情報の同期は Chrome アカウント全体のひとつの選択ですが、設定同期を有効にしたデバイスだけが参加し、それ以外のデバイスはローカルの認証情報を使い続けます。新規ユーザーでは認証情報の同期は既定で無効です。アップグレード時に Chrome Sync に空でない認証情報がすでに存在する場合は、データ損失を避けるため有効のまま維持されます。有効にすると、API キー、トークン、パスワード、エクスポート先の認証情報が Chrome Sync 経由で共有されますが、難読化されるだけで暗号化はされません。保存済みブックマーク、ページ内容、オフラインキューは Chrome Sync には入りません。AI リクエストは、オンにした、または使用した AI 機能から**のみ**発生し、設定したプロバイダーに直接送信されます。インストール時に許可されるのは Pinboard へのアクセスだけです。そのほかに拡張機能が必要とするサイト（AI プロバイダー、エクスポート先やアーカイブ先、辞書、Google ドライブ、動画の字幕、一括保存の対象サイト）は、その機能を初めて使うときに、正確なサイトを 1 つずつ要求します。カスタムのネットワークエンドポイントには HTTPS が必要で、HTTP は `localhost`、`127.0.0.1`、`[::1]` に限り許可されます。拡張機能の各ページは厳格な Content-Security-Policy（リモートコードを禁止）を適用しています。詳細ポリシー: <https://pine2d.github.io/Pinboard-Bookmark-Enhanced/privacy.html>

Google ドライブ は端末ごとに接続すると、個人ライブラリの単語帳、ハイライト、メモ、AI 辞書項目と追加用法、保存した質問と回答および引用元の抜粋を同期します。非公開の appDataFolder に保存されるコピーは平文で、エンドツーエンド暗号化はされません。必要に応じてウィクショナリーから語源資料を取得し、原文を照合した短い抜粋と出典情報を、選択した AI プロバイダーに送信します。用法のポイントの例文は AI が作成します。原文の用例は Wikisource で検索してそのまま表示し、翻訳はせず、AI にも送信しません。生成済みの結果は保持され、更新を要求したときだけ新しい版を生成します。

単語帳を同期するすべての端末で拡張機能を更新してください。新版は既存の単語データを読み込めますが、旧版では新版が保存した単語の変更を受信できません。
