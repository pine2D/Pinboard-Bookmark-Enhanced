## 结论与范围

保留现有主题、平铺笔记画布、控件阶梯、Lucide stroke 2、快 CJK 字体和零运行时依赖。优先改善草稿保护、失败反馈、窄窗布局和长任务控制，再补齐整理、发现与配置路径。

研究覆盖 popup、options、library、md-preview 和站点主题。基于源码、既有设计规范、隔离 Chromium 的合成账号/文章/词条及本机 AI mock；不读写真实用户数据，不向真实服务提交。原始运行共生成 204 张截图，人工复核关键状态；包括 52 个设置宽度场景、8 个 Ask 宽度和 16 个长语言舒适/紧凑窄窗场景。主题预设代表状态共 92 图，并非所有主题×语言×状态的穷举。

## 证据、标准与限制

`evidence/` 保存关键原始截图及 JSON 测量；完整临时目录为 `/tmp/pbp-ui-ux-20261007`，不是长期保存依赖。所有内容均为虚构夹具。

- [Chrome popup 生命周期](https://developer.chrome.com/docs/extensions/develop/ui/add-popup)：失焦自动关闭，因此草稿需在编辑时保存。
- [W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：320 CSS px 用于窄窗/高倍率缩放验收。
- [W3C Status Messages](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：状态需要可感知且不过度播报。
- 项目依据：`docs/theme-surface/COMPONENTS.md`、`.claude/rules/`、现有 owner/权限/存储安全边界。

主题对比度工厂审计 PASS；通用检测器的38条提示包含密度、级联和既定设计误报，未作为38个缺陷。连续笔记旅程首次超时，独立复跑9图全部通过，保留间歇项，不凭一次超时认定产品失败。九语言截图中的6次 ERR_ABORTED 来自夹具立即重载打断语言请求，聚焦复测未出现；429错误为有意注入。

研究未证明 Windows 高 DPI 冷字体、真实屏幕阅读器、真实视频登录字幕、真实 Drive/Anki/导出服务及大数据量性能。实现验收不虚报这些外部环境结果；新增网络出口或AI触发面必须同步隐私文档。
