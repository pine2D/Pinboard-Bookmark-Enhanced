# 词源、相关词与 AI 补充用法：调研及实施备忘

日期：2026-10-25。用户已批准按本稿实施；本节保留实施前结论，完工后追加对照及复审记录。

## 目标与边界

面向不同母语、不同学习语言的使用者。解释、判断和引文释读默认使用明确设置的母语；手动指定 AI 释义语言时尊重该选择；未设置时明确显示回退语言。原词、例句和真实引文保留其语言，附译文。学习水平调节说明难度，不改变原文及事实。

维持现有查词入口与按需补充，不增加一排 AI 按钮。基础词条不发送文章或词典包内容；补充发送已生成词条、学习资料及必要公开证据。付费结果永久保留；更新由用户明确触发，创建新版本，完整结果与证据继续同步。

## 实施前问题

1. 文学/文化仅取前三条搜索摘要，没有读取原段落或检查体裁。Wikisource 也收录法律、报告等，正文命名空间不是文学分类。
2. 补充提示词要求不重复基础词条，但实际没有发送基础词条或其中的含义。
3. 母语只作背景资料；输出依赖释义语言，返回内容没有语言检查。
4. 七类补充统一返回单一 content 字符串，无法分别检查需要的内容与引用。
5. 词源与相关词缺乏结构：历史、现代构词、记忆联想未分层，相关词没有说明关系。

## 逐类内容规范

| 内容 | 用户价值与结果要求 |
| --- | --- |
| 词源 | 现代构词、可核实历史来源及其与现代意思的联系分开；没有历史资料就留空，不编拆字故事。 |
| 相关词 | 默认最多五个，说明词族、同源、近义或同主题关系及区别。 |
| 搭配 | 按含义组织表达形式、意思、场景、原创例句与译文；无语料统计不宣称最高频。 |
| 易混词 | 两三个真正容易混淆的词，同场景比较及选择原则，不编互斥规则；母语明确才讨论该语言对的假朋友词。 |
| 语体/地区 | 区分正式程度、领域、地区和语气；必要时给中性替代表达，没有显著差异不凑数。 |
| 语法 | 针对学习语言给最相关的一至三点：形式/句型、例句及解释；不统一套英语语法模板。 |
| 场景 | 二至三个不同交际目的的原创示例或短对话，结合可选主题与水平，明确为 AI 编写。 |
| 文化/网络 | 具体表达、圈层/平台、含义与语气、时间及可核实出处；一次命中不等于起源或流行程度。 |
| 文学 | 一至两例，含作者、作品、章节、真实短引、译意、情境及此处用词效果；排除法律、报告、目录与作品介绍。 |

保存释义菜单只负责保存，不暗中决定补充内容范围。补充接收基础词条，多义时明确分组。文本、结构、语言和证据分开验证；原文从取得的正文中提取，模型不得制造引文或 URL。无证据允许失败，不用空泛生成填充。

## provider 的核实例证

- [V2EX provider](https://www.v2ex.com/d/provider)：直接读取失败后经 Jina 读取。词源链条易理解，但相关词关系未标注；文学段只提《傲慢与偏见》《简·爱》以及 provide/provision 等相关表达，未给 provider 的具体引文，不能照用为实证。
- [Etymonline provider](https://www.etymonline.com/word/provider)：provider 是 provide 的行为者名词；provide 追溯至拉丁语 providere，涉及向前看、预作准备与供给。现代构词和历史来源应分开呈现，不把记忆提示当史实。
- [狄更斯《匹克威克外传》第十四章](https://en.wikisource.org/wiki/The_Works_of_Charles_Dickens/Volume_1/Chapter_14)：原文 “Thoughtful creature! Comfortable provider!” 出现在女主人介绍早餐后。provider 指提供生活照料的人；结合上下文可读出 Tom 对舒适生活的私心与喜剧意味，后者属于释读。
- [Edith Summers Kelley《Weeds》第一章](https://www.gutenberg.org/cache/epub/61201/pg61201-images.html)：原文 “as bountiful a provider” 用于家庭供养者评价，随后有按当地标准的限定。两个实例只能说明各段实际用法，不能证明文学中的频率。

## 方法与来源

- [SKELL](https://www.sketchengine.eu/skell/) 区分真实例句、搭配和相似词；自动相似词不一定同义。
- [Word Sketch Difference](https://www.sketchengine.eu/guide/word-sketch-difference-compare-words/) 用搭配差异帮助辨析，优于并排复制定义。
- [RAE CORPES XXI](https://www.rae.es/banco-de-datos/corpes-xxi) 强调文本种类、地区、时间及真实语料范围。
- [IDS grammis](https://grammis.ids-mannheim.de/progr@mm/6876) 与 [FundéuRAE depender de](https://www.fundeu.es/recomendacion/depender-con-la-preposicion-de/) 展示语言特定的句型和介词问题。
- [Wikisource 收录范围](https://en.wikisource.org/wiki/Wikisource:What_Wikisource_includes)、[MediaWiki 搜索 API](https://www.mediawiki.org/wiki/API:Search)：搜索片段不等于完整语境，必须另取正文与元数据。
- [Gutenberg 自动访问政策](https://www.gutenberg.org/policy/robot_access.html)：普通网站不能直接作实时抓取 API；未来精选语料应使用其允许的获取路线。本轮不接入实时 Gutenberg 抓取。

## 已批准的施工顺序与验收

1. 语言与释义上下文：默认规则可理解，明确用户选择优先；按已有释义组织补充。
2. 文学和文化取材：候选检索、正文、体裁/来源定位、精确词形匹配；无来源不调用 AI。
3. 分类输出：各类结构化内容，正确语言、必要字段、引文一致性和重复控制。
4. 展示：复用现有折叠与按钮，气泡精简、library 充分利用阅读空间；键盘、取消、错误及保存失败恢复完整。
5. 保存同步：新格式兼容旧结果，手动更新保留全部付费版本，原文证据随结果同步。
6. 复审：相关逻辑测试、跨语言/窄窗/主题渲染、快速折叠与减少动态效果、焦点/滚动、取消/迟到响应、跨设备格式与旧记录兼容；完成后对照本稿逐项记录实际结果和限制。
