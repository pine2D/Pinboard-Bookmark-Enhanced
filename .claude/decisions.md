# 裁决登记册

> 记录用户拍过板的取舍和已否决的方案。提新功能、做界面评审、做审计之前先读一遍：这里列出的事不要再当新发现或新建议提出来。确有新证据要翻案，先说明新证据是什么。派子代理做评审或审计时，把相关条目写进提示词，作为不报清单。
>
> 2026-11-10 建立。首批条目整理自此前各次会话的记录，只收了明确由用户拍板的，可能不全，发现遗漏就补。新裁决加在所属小节表格的最后一行。
>
> 格式由 `scripts/registers-lint.mjs` 检查：每张表四列，日期写 `YYYY-MM-DD`，同一天的同一条裁决只写一次。
>
> 放在 `.claude/` 根而不是 `.claude/rules/`，理由同 `.claude/expiring-items.md`：不随文件匹配自动加载，也不会被 GitHub Pages 发布。
